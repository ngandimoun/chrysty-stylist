# Chrysty AI Stylist — V1 Exclusion List

Do not build in V1:

- Dashboards, analytics, style scores, admin panels
- Marketplace, shopping links, checkout
- Social feed, sharing, followers
- Tab bar (Closet / Home / Profile)
- Full closet grid, outfit history grid
- Virtual try-on, trend reports, style quizzes
- Auth UI (cookie workspace only)
- Queues, Redis, second backend service

Review question: *Stylist in your pocket, or app platform?*
