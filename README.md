# Chrysty AI Stylist

Personal AI stylist — photo-first wardrobe, conversational styling, masonry outfit looks.

## Setup

1. Copy `.env.example` to `.env.local`
2. Apply `supabase/migrations/20250615000000_init.sql`
3. Create private buckets: `wardrobe`, `outfits`
4. `npm install && npm run dev`

See `docs/V1_EXCLUSIONS.md` for scope guardrails.
